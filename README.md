# 文档保留台账（document-retention-register）

面向档案管理员的离线命令行工具：登记文档类别与保留年数、管理法务保留、
查询销毁资格，并通过“预览清单 + 确认”两步完成销毁登记。仅使用 Go 标准库。

## 运行

```sh
go run . --state 状态路径 --input 命令.json
```

每次执行读取一个命令 JSON 文件，向标准输出返回 JSON 结果，并把状态保存到
`--state` 指定的本地文件（先写临时文件再替换，失败不改状态）。状态文件不
存在时自动创建空台账，因此重启后可用同一状态路径继续操作（包括确认此前
预览生成的清单）。

## 命令格式

所有日期均为 `YYYY-MM-DD`。通用字段：`operation` 指定操作，其余字段按操作提供。

| operation | 字段 | 说明 |
| --- | --- | --- |
| `register-category` | `category`, `years` | 登记类别及保留年数（正整数），重复类别拒绝 |
| `register-document` | `document`, `category`, `start_date` | 登记文档，关联已登记类别与起算日期，重复标识拒绝 |
| `add-hold` | `document`, `hold` | 为文档添加具名法务保留 |
| `remove-hold` | `document`, `hold` | 解除一个具名保留 |
| `query` | `document`, `date` | 查询该日期的到期日与状态（只读，不改状态） |
| `preview` | `date` | 生成该日期全部可销毁文档的清单并保存，返回 `list_id` |
| `confirm` | `list_id`, `date` | 引用清单编号并按确认日期整批确认销毁 |

示例（登记类别）：

```json
{"operation": "register-category", "category": "合同", "years": 3}
```

失败时输出 `{"ok": false, "error": "..."}` 并以非零码退出，状态保持不变。

## 保留期与资格规则

- 到期日 = 起算日期 + 类别保留年数；2 月 29 日起算遇目标非闰年取 2 月 28 日。
- 到期日当天即可销毁。
- 每份文档可有多个具名保留，全部解除后才恢复资格。
- 查询状态优先级：已销毁 > 被保留 > 未到期 > 可销毁。
- 已销毁文档继续可查（含销毁日期与清单编号），且禁止任何修改。

## 销毁确认规则

- `preview` 保存带唯一编号（`LIST-0001` 起）的清单，内容为该日期全部可销毁文档。
- `confirm` 必须引用清单编号并提供确认日期，确认日期不得早于预览日期。
- 确认时按当前台账逐项重新检查资格：任一项已销毁、被保留或未到期均拒绝整批。
- 清单之外后来登记或到期的文档不会混入确认；空清单不能确认。
- 成功后保存确认日期并把整批标记为已销毁；不删除任何真实文件。

## 重启后继续确认清单示例

```sh
# 第一次运行：预览，清单与状态一起落盘
go run . --state ledger.json --input preview.json
#   输出 {"list_id": "LIST-0001", ...}

# 进程退出后，任意时刻再次运行：用同一状态文件确认该清单
go run . --state ledger.json --input confirm.json
#   confirm.json: {"operation": "confirm", "list_id": "LIST-0001", "date": "2026-10-01"}
```

```sh
go test ./...
```

测试覆盖闰日起算边界、多保留解除、预览后新增保留导致整批拒绝、
清单外文档不混入、空清单拒绝、销毁记录跨重启可查等场景。
